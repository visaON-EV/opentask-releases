# OpenTask Desktop — instaladores

Instaladores do **OpenTask Desktop** (Elétrica Visão), aplicativo de chamados de TI para Windows 10/11 (64 bits).

- Baixe a versão mais recente em **[Releases](../../releases/latest)**.
- O aplicativo instalado se atualiza sozinho: ele só aceita versões cujo manifesto foi assinado pela chave do TI
  da Elétrica Visão e confere o SHA-256 de cada instalador. Este repositório só hospeda os arquivos.

Dúvidas: setor de TI da Elétrica Visão.
